# Noto Sans

Fontes incorporadas ao PDF para preservar a tipografia e os acentos mesmo sem a fonte instalada no dispositivo. Carregadas apenas durante a exportação; os dados financeiros são processados no navegador.

Origem: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Arquivos originais `NotoSans-Regular.ttf` e `NotoSans-Bold.ttf`, distribuídos sob a licença SIL Open Font License 1.1 em `OFL.txt`.
